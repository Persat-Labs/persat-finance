Devnet Keypair Generator

Persat Finance — Testnet Sprint · Day 0

How this protects you

This page runs entirely in your browser. Keypairs are generated with your machine's WebCrypto engine, are never sent anywhere, and are not stored. Work offline if you like — download this file first and open it locally.

Generate once, save the download, then follow the three steps below. If you lose a program keypair, that program address can never be used again (recoverable, but it costs a redeploy and new IDs).

Step 1 — Generate

Creates 12 keypairs: 8 program IDs, 1 deployer wallet, 3 governance signers.

Step 2 — Paste the public keys into the Arena chat

Public keys only — always safe to share. Arena updates declare_id!s and the manifest with them.

Step 3 — Upload secrets to GitHub, then fund the deployer

Repo → Settings → Secrets and variables → Actions → New repository secret. For each row below, create a secret with the exact name shown, pasting that row's keypair JSON (the […64 numbers…] text) as the value. The download from Step 1 contains one labelled file per keypair so you can copy them one by one.

No secret needed for governance signers 2 and 3 — keep those keypairs offline. They exist so no single wallet controls the protocol.

Then fund the deployer: copy the deployer's public key and request Devnet SOL at faucet.solana.com (repeat until it holds ≥ 25 SOL; program deploy rent is the bulk of the cost). solana airdrop 2 <deployer-pubkey> --url devnet also works if you have the CLI.

Already have Solana CLI?

Equivalent, if you prefer the terminal:

for n in governance price_oracle asset_whitelist deal_registry escrow_vault loan_lifecycle liquidation_engine fee_treasury deployer gov1 gov2 gov3; do solana-keygen new --no-bip39-passphrase -o "persat-$n.json"; done
